# Мок-версия сайта по ТЗ (десктоп 1440, вариант 1 — основной)

## Цель
Полный многостраничный сайт-мок по финальному сету Figma «💚vol.2 - finals» (сетка 1200) и структуре ТЗ: ~15 страниц + 4 формы, всё на мок-данных, без бэка. Главная остаётся наша (index-1), index-2 остаётся в репо, но в навигацию не входит. Формы — отдельные страницы. Без адаптива (десктоп-first).

## Архитектура
```
career-portal/
├── build.py              # расширить: сборка всех страниц из layout+фрагментов+моков
├── data/                 # мок-данные JSON (генерят повторяющиеся списки)
│   ├── companies.json    # 43 компании из Приложения 2 ТЗ (сегменты)
│   ├── vacancies.json    # ~12 вакансий (город, регион, опыт, специализация, ЗП, теги)
│   ├── internships.json  # практики+стажировки (теги «Оплачиваемая», график)
│   ├── events.json       # ~8 предстоящих + ~6 прошедших
│   ├── articles.json     # ~9 материалов (статья/видео/подкаст, рубрики)
│   ├── educat.json       # предложения целевого обучения + ВУЗы/СУЗы
│   └── faq.json          # вопрос-ответ для разделов
├── src/
│   ├── blocks/           # существующие блоки главной (не трогаем)
│   ├── layout/           # НОВОЕ: header/footer финального сета (сетка 1200)
│   └── pages/            # НОВОЕ: контентные фрагменты внутренних страниц
└── *.html                # собранные страницы ( vacancies.html, vacancy.html, ... )
```
Повторяющиеся списки (карточки вакансий, мероприятий, статей) генерирует build.py из data/*.json — статичный HTML в итоге (по ТЗ контент без JS).

## Шаги
1. **Разведка finals**: выгрузить спеки header/footer финального сета (сетка 1200 — вероятно отличается от нашей 1360), типографику, общие компоненты (кнопки, теги, карточки, фильтры, пагинация, хлебные крошки); выгрузить недостающие ассеты (фото вакансий, мероприятий, статей, компании, карьерных треков, герои лендингов).
2. **Каркас**: layout (header/footer), базовые компоненты, расширение build.py (многостраничная сборка, генерация списков из data/*.json, кэш-басинг).
3. **Мок-данные**: data/*.json по количественным ориентирам ТЗ (5 лозунгов уже есть; 12 вакансий; 43 компании; 12+6 мероприятий; 9 материалов; до 15 треков — сделаю 4-6 с 5-7 ступенями; FAQ по 5+).
4. **Страницы по порядку** (каждая: верстка → сверка с рендером макета → навигационные ссылки): вакансии (3 стр.) → стажировки (3 стр.) → целевое (2) → мероприятия (4) → медиа+статья → карьерный трек → компания → 404.
5. **Мок-валидация форм**: required-поля, блокировка сабмита, success-состояние (JS, без отправки).
6. **Навигация**: перелинковать меню/футер/кнопки главной на новые страницы (главная остаётся index-1).
7. **Финал**: проверка консоли, битых ссылок, сверка скриншотов каждой страницы с макетом; README дополнить картой страниц.
