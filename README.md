# career-portal — вёрстка портала карьеры «Интер РАО»

Статическая вёрстка по макету Figma **CP_Ревью** (страница «⚜️ Концепция»): два варианта главной страницы, порезанные по компонентам под интеграцию в Битрикс.

- **Демо:** [index-1.html](index-1.html) — «Концепт — Главная 1», [index-2.html](index-2.html) — «Концепт — Главная 2»
- Никакой сборки не требуется: чистый HTML + CSS + vanilla JS.

## Структура

```
career-portal/
├── index-1.html            # демо-сборка варианта 1 (сгенерирована build.py)
├── index-2.html            # демо-сборка варианта 2 (сгенерирована build.py)
├── build.py                # сборка демо-страниц из фрагментов блоков: python build.py
├── css/
│   ├── variables.css       # дизайн-токены: цвета, типографика, радиусы, сетка
│   └── base.css            # шрифты (Golos Text, локально), normalize, .container
├── assets/
│   ├── fonts/              # Golos Text 400/500/600 (woff2, cyr+lat)
│   ├── images/             # фото и иллюстрации из макета
│   ├── icons/              # SVG-иконки + логотип (PNG-фолбэки)
│   └── logos/              # карточки логотипов работодателей (PNG @2x)
└── src/blocks/<block>/     # КОМПОНЕНТЫ: независимые фрагменты
    ├── <block>.html        # разметка блока
    ├── <block>.css         # стили блока (БЭМ)
    └── <block>.js          # логика (не у всех блоков)
```

## Интеграция в Битрикс

1. **Шрифты и токены**: подключить `css/variables.css` и `css/base.css` (например, как `template_styles.css` или через объединение в настройках шаблона).
2. **Шапка/подвал**: `header.html` и `footer.html` переносятся в `header.php` / `footer.php` шаблона. Пункты меню — на `$APPLICATION->IncludeComponent("bitrix:menu", ...)`.
3. **Блоки**: каждый `src/blocks/<block>/<block>.html` — самостоятельный фрагмент, вставляется в нужную страницу/включаемую область; стили блока подключаются рядом (или все скопом — порядок в `build.py: CSS_ORDER`).
4. **Данные для JS**: карусель «Производство» и попап «Направлений» читают данные из `<script type="application/json">` внутри своей разметки — при интеграции эти JSON удобно заменить выводом из инфоблоков (`json_encode` в шаблоне компонента).
5. **Ссылки-заглушки**: `href="#"`, `action="/vacancies/"`, `action="/search/"`, `mailto:` и телефон — заменить на реальные. Слайдер/попапы работают без внешних библиотек.
6. **Формы**: поиск в hero и панель «Найди свою вакансию» — обычные GET-формы; на стороне Битрикса указать свои обработчики.

### Пересборка демо-страниц

После правки фрагментов в `src/blocks/`:

```bash
python build.py
```

## Примечания

- В макете только десктоп (1440); адаптив 1024/768/375 сделан по тем же компонентам на усмотрение.
- Скрытые в макете альтернативы (тёмная секция работодателей, компактная панель с селектами) не включены; их легко добавить как модификаторы по тому же принципу.
- `.figma-token`, `.figma-cache/`, `.shots/` в git не попадают (см. `.gitignore`).
